Privacy policy

Gavin · last updated 23 November 2026

Gavin is a private personal assistant used by one person, its owner. This page explains what Gavin does with data from the owner's Google account.

What Gavin accesses

With the owner's permission, Gavin reads the events on the owner's Google Calendar, creates events on a calendar named "Gavin", and deletes an event only after the owner taps Approve. Gavin does not access any other person's Google account.

How the data is used

Calendar data is used only to give the owner reminders, a daily brief and answers about their own schedule. To write those messages, Gavin sends the relevant calendar details to Anthropic's Claude API, which processes them to produce a reply. Nothing else is done with the data.

Where it is stored

Gavin runs on the owner's own computer. Its memory is kept in a local file on that computer. The owner can tell Gavin to forget something, which erases it, including from backups.

Sharing

Google user data is not sold, not used for advertising, and not shared with anyone other than the processing described above. Gavin's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove Gavin's access to their Google account at any time at myaccount.google.com/permissions.
